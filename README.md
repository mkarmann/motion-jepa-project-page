# MotionJEPA project page

Source for the [MotionJEPA](https://github.com/mkarmann/motion-jepa) project website, based on the [Nerfies](https://github.com/nerfies/nerfies.github.io) template.

## Local preview

```bash
cd project-page
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## GitHub Pages

Serve from the `main` branch, site root (`/`). After Pages is enabled, the site is at:

https://mkarmann.github.io/motion-jepa-project-page/
